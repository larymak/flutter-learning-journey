# Dart & Flutter Learning Journey

A public learning journal documenting my journey from Dart fundamentals to building and shipping Flutter apps for mobile and web, contributing to open source, and growing as a Flutter community educator.

## Goals

- Build production-quality Flutter applications for mobile and web.
- Develop professional Dart, testing, architecture, and debugging skills.
- Contribute useful documentation and code to the Flutter ecosystem.
- Share practical tutorials and eventually work toward Flutter Google Developer Expert recognition.

**Approach:** Learn → Build → Document → Contribute

## Running the exercises

Install the stable Dart SDK (or Flutter, which bundles Dart), then run:

```bash
dart run dart-fundamentals/exercises/developer_profile.dart
dart run dart-fundamentals/exercises/learning_tracker.dart
dart run dart-fundamentals/exercises/shopping_cart_refactored.dart
```

Alternatively, paste each exercise into [DartPad](https://dartpad.dev/).

## Documentation principles

1. Keep examples small, executable, and beginner-friendly.
2. Explain why a solution works, not just what to type.
3. Record mistakes and the rules learned from them.
4. Link to official documentation and revisit notes as understanding improves.
